# SmashTutor notebooks

AI can already explain almost anything. Learning on purpose takes more: a program, a clear order of topics, a placement test, careful answer checking and saved progress. SmashTutor gives you all of that for free, inside your own ChatGPT.

This repository holds free practice notebooks that go with the SmashTutor courses in Python and in AI and machine learning. Each notebook explains one topic in short steps, shows runnable examples, and ends with exercises that check your answers with `assert`. They run in the browser in Google Colab, or on your own computer with Jupyter. No API keys or paid accounts are needed; Colab asks you to sign in with a Google account, Jupyter on your own computer needs nothing.

## How to use them

- **In the browser:** click "Open in Colab", then run the cells from top to bottom with Shift+Enter. Use "File → Save a copy in Drive" to keep your answers.
- **On your computer:** install Python 3, then run `pip install jupyter numpy` and `jupyter notebook` in this folder.
- In each exercise replace `None` with your answer and run the check cell under it. It says "not answered yet" until you answer, "correct!" when you are right, and gives a hint when you are not.

Who they are for: anyone starting Python from zero, and anyone with school algebra and a little Python who wants to see how machine learning math works in code.
